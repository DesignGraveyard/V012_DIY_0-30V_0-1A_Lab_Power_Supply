# Description

Build a cheap and reliable 0–30V, 0–1A bench power supply using standard components like the LM317 and NE555. 
This design is based on a ON-Semiconductors application note but simplified with common “jellybean” parts and a NE555 charge pump to generate the negative voltage reference to achieve output control down to 0 Volt & 0 Ampere.

The video below shows the power supply in action, assembly tips, how to manage the thermals, a LM317 offline HTML tool including losses and an explanation how it works!
